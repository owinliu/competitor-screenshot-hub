# 产品页面内容边界原则

更新时间：2026-05-20

## 核心原则

网站页面只展示用户需要消费的结果，不主动暴露内部实现、筛选逻辑、调试状态或项目管理信息。

除非用户明确要求查看，否则不要在页面中展示：

- 内部筛选口径：如“当前达标 2 个”“其余 33 个暂不展示”。
- 实现说明：如“后台框架”“本地 API”“执行器”“golden-flow-radar 如何沉淀”。
- 本地文件路径：如 `/Users/...`、`sourcePath`、输出物绝对路径。
- 调试/开发状态：如 API online/offline、localhost、未接入、可生成草稿。
- 数据治理标签：如待分类、分类状态、复核状态、sourceType、导入状态。
- 面向开发者的解释文案：如“避免混淆”“暂不进入”“页面不做复杂节点管理”。

## 页面文案写法

面向用户时，文案只回答三件事：

1. 这里能看什么。
2. 这个结果说明了什么。
3. 用户下一步可以怎么使用。

内部判断可以保留在代码、数据字段、文档或管理界面中，但默认不出现在用户页面。

## 黄金流程页专项规则

黄金流程页只展示：

- 流程名称。
- 完整流程证据图。
- 主路径说明。
- 必要的补充说明。

不要展示：

- 达标数量与隐藏数量。
- golden-flow-radar 项目路径或输出文件路径。
- 文字版/证据图/页面转译的产物状态面板。
- 后台生成框架说明。
- 普通截图流程中的错误节点截图。

如需展示原始证据截图，必须接入 `radar/golden-flow-radar/evidence/...` 对应文件夹中的真实证据，不能复用普通截图库的关联截图。
